## Four law states

1. **APPLY / TEST** — an intervention earns prospective authority.
2. **ABSTAIN** — no structural intervention currently earns authority.
3. **REVOKE** — an earlier structural extension/abstraction relation loses authority.
4. **UNRESOLVED** — current evidence does not adjudicate the boundary.

These states are not interchangeable.
