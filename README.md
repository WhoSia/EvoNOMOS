# EvoNOMOS

Canonical GitHub repository for EvoNOMOS research execution artifacts, preregistrations, branch-local harnesses, and migration receipts.

- Research repository: `WhoSia/EvoNOMOS`
- External software repositories such as `WhoSia/Kodo-web` are world-contact substrates only.
- Historical external SHAs/runs remain cited as provenance, but new EvoNOMOS workflows and credentials must live here.

## Repository workflow

`main` is the canonical working branch. Do not create one branch per DIP stage, world-contact gate, provider check, experiment snapshot, or historical checkpoint. Temporary branches are allowed only for genuinely risky work and should be merged or deleted promptly.

GitHub is the compact executable evidence layer, not the historical archive. Preserve scientific history in Notion, Google Drive, commit SHAs/tags, and frozen receipts rather than by accumulating long-lived remote branches.

At every generation or major phase transition, retire superseded branches and obsolete execution scaffolding that are no longer required to reproduce or interpret the current lineage.

See `REPOSITORY_POLICY.md` for the full hygiene rule.
