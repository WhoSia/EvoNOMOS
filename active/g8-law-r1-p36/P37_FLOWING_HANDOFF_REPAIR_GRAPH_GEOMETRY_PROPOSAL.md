Y_i := (1[F_i != empty], min_{r in F_i} verified_cost(r),

The minimum is **portfolio- and budget-relative**, never the globally minimal source patch. No claim an impossible repair means universally impossible under a broader Γ.

This is a model specification, not a completed computed graph or proof of sufficiency.

## 3. Meaningful competing models and a statistical differentiator

The strongest specified classical rival `B_*` is **not** SOLID, LOC, a scalar modularity rank, a naive parser-entropy threshold, or 'both outputs are equal so patches must behave the same'. It knows:
- source-level AST/call graph and program slicing / dataflow / change-impact analysis;

- previous benchmark-calibrated source-runtime costs and memory-allocation vectors;
- explicit repair edit grammar Γ, public API ownership/migration, test coverage and historical overfitting risk;
- nested heldout tests, repo/project effects and performance environment.

`B_*` is calibrated **without** the proposed demand-specific repair-graph summary `G_i`, but includes all classical raw information and source mechanisms. This is a legitimate nested-model baseline; an advanced classical analyst could itself derive `G_i` from its available inputs. Therefore improvement over `B_*` would show **incremental predictive usefulness of a chosen feature** for finite data, *not* that classical theory was logically defeated.

`H_G`: a calibrated model augmenting **the same features and information** as `B_*` with a preregistered bounded feature vector `G_i` computed from sources and frozen demands *without reading repair outcome*. The two rival quantitative predictions for **new independent holdout sources**:
```
H_G: mean_holdout[ logloss(B_*) - logloss(H_G) ] ≥ 0.05 nats/episode
B_*: mean_holdout[ logloss(B_*) - logloss(H_G) ] ≤ 0 (no positive incremental gain).
```
The ≥0.05 threshold is an **ambitious chosen criterion**, not estimated from O12, and must be frozen *before* future holdouts are selected. A proper claim also needs cluster-bootstrap uncertainty by repository with a confidence interval excluding 0 and calibration inspection. Using only two repos, a single hand-picked witness or outcome-leaking graph constructions **cannot** adjudicate. The two stated models disagree on prospective **measurable log-loss gain**, unlike an unfalsifiable slogan; which one wins is unknown.

**Critical epistemic guard**: the above difference is an operational statistical *feature-comparison* hypothesis, not a theorem that a new law is outside abstract interpretation, data provenance, program slicing or APR. Genuine law-level novelty would additionally require a simple invariant / conditional mechanism with counterfactual transport and a clear mathematical separation from all strong prior equivalents.
