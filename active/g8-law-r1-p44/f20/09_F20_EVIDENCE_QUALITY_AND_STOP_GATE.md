# F20 evidence quality scale and early stopping

C0: chosen maintainer claim with no source bytes.
C1: original GitHub parent/post SHA and metadata read.
C2: original diff/issue with exact file paths, negative and positive tests identified.
C3: native Go build at parent/post original tree with environment receipt.
C4: source-aware client oracle and matched classical rivals run with predeclared observer.
C5: genuine chronological sealed prediction before later demand exposure; THIS IS NOT ACHIEVED by looking at historical GitHub commit messages.

Now C1, and no proof higher without tools. If upstream patch is unavailable or CI fails, mark source retrieval or environment/semantics separately. Do not silently replace or 'fix' upstream to force PASS. If C4 classical rivals fully explain, mark TIE rather than lawnovelty. If no valid timestamp evidence of pre-reveal information, no nonanticipatory claims.

## Research authority and evidence limits
- These are **historical published commits**, not blinded future events. The commit SUBJECTS and changed filenames already disclose some outcome information before any source patch read.
- The selected code is owned by external upstream maintainers; our permission to build a public copy is not authenticated authorization to edit their canonical repository or to represent their policy.
- A Git commit SHA identifies a repository object; full source byte verification and self-contained executable baseline receipts remain separate obligations.
- A researcher-selected cohort, not statistically random or independently blind. No outcome prediction, causal novelty, G1–G7 closure or law promotion from metadata alone.
