# Permission lattice and synthetic cost

Rights pi allow editing application-owned Capture(view) logic, application test handler registration and the fixture; upstream middleware/request_id.go, Go runtime, Chi router internals and global RequestIDHeader are not editable.

One named repair choice switches the captured View from live pointer alias to a copied value at middleware entry. The defined synthetically priced edit cost is 1 for either stdlib-backed or chi-backed application, conditional on the chosen app edit grammar.

Do not treat one syntactic flag flip as measured developer labor, or assert this is minimal over all possible code changes: a different middleware ownership architecture may require different edits, testing or deployment work. Record the cost vector (source files changed, diff lines, tests, effect footprint, reviewer rights, human time) as mostly unknown until source edits are reviewed and instrumented.
