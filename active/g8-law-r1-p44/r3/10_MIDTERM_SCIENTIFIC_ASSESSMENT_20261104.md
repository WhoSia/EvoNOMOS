## Scientific weaknesses
1. Original-source coverage remains bounded and constructed around Chi/ServeMux; one external issue is reproduced, but most source graphs and task demands were investigator-designed.
2. A good original-source executable test is not a sound source analyzer. Current AST checks verify syntax facts, not whole-program alias, contextual equivalence or completeness.
3. Strong rivals already explain the entire evidence. There is no isolated prediction gain over exact classic transition search under equal information.
4. Synthetic edit count is not developer effort, onboarding, maintenance burden, bug probability or deployment/review costs. No controlled engineer study.
5. Selected bounded client probes and explicit deterministic schedule leave unobserved request methods, byte-equivalence, middleware ordering, concurrency interleavings.
6. G1–G7 general source certification remains unclosed, LAW-R2 HOLD; easy router tasks cannot license broad claims.

## Critical methodological theorem (standard, not novel)
For a **fixed** finite, fully known original edit transition system and full access to source semantics, an exact exhaustive classical search computes safe feasibility/cost on that grammar. A newly named EAC formalism cannot improve correctness over this exact oracle. Any genuine contribution must improve proof-certificate succinctness, analysis running cost, compositional transfer, bounded observer discovery, or real task performance under equal budgets.
