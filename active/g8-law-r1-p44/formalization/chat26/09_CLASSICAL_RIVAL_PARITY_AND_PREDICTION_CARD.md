## Classical competitors with equal resources

1. An ordinary labelled transition-system search with explicit rights and allowed edit operations.
2. Program slicing and Go AST/type/effect/alias evidence for edited source footprints; note soundness/incompleteness.
3. Jones-style rely–guarantee reasoning for stateful middleware and temporal aliasing.
4. Existing modular design-operator / option value theory (Baldwin–Clark) for expected future recourse.
5. Contractual source-specification mapping (Abadi–Lamport) when abstract/concrete refinement is invoked.

Comparison needs distinguishable predicted customer outcomes or verification/effort advantages under the same information. If all rivals predict the same, log **TIE** instead of rebranding the common result.
