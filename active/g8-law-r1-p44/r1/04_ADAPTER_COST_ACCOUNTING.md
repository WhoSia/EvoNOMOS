# Initial normalization must not be treated as free

The earlier two-stage route-insertion tie had cumulative 0,1,2 edits for both libraries after an implicit baseline normalization.

For the declared P44 app-edit grammar, normalization is 0 for stdlib and H+D+M=3 for Chi if all three are needed. Subsequent two named route-addition demands then yield cumulative synthetic cost vectors:
stdlib [0,1,2], Chi [3,4,5].

These vectors are relative to raw initial installations and an observer set chosen for this experiment. They do NOT show an intrinsic cross-ecosystem software-design superiority, because adapter work, API ecosystem constraints, middleware configurations, developer familiarity, and other possible repair grammars vary.

The sound comparison separates:
(1) the unnormalized baseline (not observationally equivalent),
(2) normalized pair at the same contract,
(3) future repair cost conditional on normalized baseline,
(4) total cost including normalization.
