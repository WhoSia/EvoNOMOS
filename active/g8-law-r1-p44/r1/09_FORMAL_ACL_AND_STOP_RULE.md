# Evolutionary Admissibility Calculus — protocol candidate and off-ramp

An admissible repair path requires:
O0: observer scope and layer declared.
R1: each source change authorized by the fixed intervention grammar.
S2: all protected client observations preserved after each prefix.
D3: demand satisfaction at each corresponding time.
C4: transparent vector-valued costs, separating normalization and subsequent repair.
V5: source-level provenance with an independent executable receipt for original-source claims.
F6: same requirement, authority and evidence budget for all compared structures.

These are research obligations in familiar formal-methods terms, not novel universal axioms. If a classical semantics under the same source evidence exactly predicts all results, promotion to LAW-R2 is prohibited.

Off-ramp: when the initial contract fails, document mismatch; when repairs exist only under broadened rights, document permission dependence; when native CI fails, preserve raw logs; when adapters match only twelve probes, label finite scope.
