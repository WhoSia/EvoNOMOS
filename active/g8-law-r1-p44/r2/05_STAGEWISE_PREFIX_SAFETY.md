# Stagewise preservation gate

At every stage s in {0,1,2,3}, instantiate each original library's app routing configuration after the allowed s route insertions. Check the same twelve old requests against both original-backed routers. Then validate every earlier realized future demand, not merely the newest one.

A final-only check could miss an intermediate regression; this path-prefix oracle is an explicit stronger protocol. However these states are independently constructed app configurations under a bounded edit grammar, not a persistent series of historical developer commits or a diff-minimized human patch series.

A negative control deliberately substitutes an incorrect baseline handler that returns WRONG. The test must detect its wrong response on GET /items/alpha, showing at least selected observation sensitivity. This control is not a completeness proof.
