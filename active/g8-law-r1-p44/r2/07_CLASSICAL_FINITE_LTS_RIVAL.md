# Strongest implemented mathematical rival in this slice

Formal states are 3-bit masks of already installed future routes, and rights are 3-bit masks of allowed application-owned route insertions. An edit sets an authorized unset bit and has unit cost. All eight states are safe under the explicitly protected old-client observer *if and only if original-source tests verify the source mapping*.

For source-state s, goal g and rights pi, missing = g \ s. A feasible repair exists exactly when missing is a subset of pi. If so, the scalar shortest path cost is popcount(missing); otherwise the goal is infeasible in this grammar.

The pure Go model exhaustively checks 8 state × 8 goal × 8 rights = 512 triples, including feasibility and cost, and verifies the 0,1,2,3 versus 3,4,5,6 ledger. Local Go 1.23.2 tests, vet and race all PASS; original-source execution is a separate gate.

This is classical reachability/shortest-path analysis; do not present it as an EAC-specific mathematical theorem. A source-aware program-analysis baseline beyond this bounded grammar remains OPEN.
