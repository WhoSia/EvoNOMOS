# R24 estimand

Let O be an explicit family of HTTP observers including method, escaped path, response status, body, Allow, Location and any later declared header/temporal projections. Let two program configurations A,B be comparable only when O(A)=O(B) over the predeclared baseline set.

For demand sequence d=(d1,...,dk), rights set pi and cost semantics c, define SafePaths(A,d,pi) as the set of allowed stagewise old-client-preserving source edits implementing the sequence.

Estimand is the *difference in stagewise feasible repair and cost frontiers* across A and B under matched O, d, pi and c.

This is a conditional outcome, not an unqualified assertion that patterns or SOLID improve maintainability.
