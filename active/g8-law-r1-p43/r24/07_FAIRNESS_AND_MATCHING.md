# Matched intervention protocol

Use one requirement sequence d and one rights vocabulary pi; do not compare patch privileges that differ.

Where APIs differ, construct adapters and include their maintenance in the declared cost accounting.

Baseline should compare outputs under the same observer. If the two adapters require different semantics, either tighten common contract or declare infeasibility.

Record asymmetries, including library version, method matching, path decoding, middleware order, context lifetime and handler ownership.
