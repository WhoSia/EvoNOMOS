# Internal validity threats

Client observation incomplete: HTTP status equivalence misses HEAD, decoded IDs, errors, method allow lists and temporal effects.

Architecture confounding: different upstream versions and adapters may violate initial contract.

Treatment leakage: selecting requirements based on discovered source differences inflates predictive accuracy.

Sequential edits: an intermediate state may violate an old client even when the final code passes.

Analyst expectancy: hypotheses derived from earlier observations cannot be relabeled blind preregistrations.
