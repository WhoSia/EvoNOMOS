**T9-B, forecast information measurability (classical):** a prediction issued at time t must be a function only of information I_t available at t. If two possible histories agree in I_t but later diverge in demanded cost or accepted source, no deterministic pre-t predictor can correctly distinguish both. Proof: equal input forces the same output despite different targets. This ordinary information-theoretic obstruction defeats false apparent blind prediction by late-feature leakage.

**T9-C, borrowed lifetime frame (conditional):** when a provider-owned context lease ends at handler return, retaining the identical mutable context requires source-enforced non-reuse or a valid transfer of ownership. A copy made **before lease end** can preserve declared route-value observations if it deeply copies every relevant mutable field; a separate retained-parent reference must itself satisfy any stronger resource-detachment requirement. This is classical ownership/alias/frame logic, fully compatible with Iris and CCR 2.0, not new separation-logic proof superiority.
