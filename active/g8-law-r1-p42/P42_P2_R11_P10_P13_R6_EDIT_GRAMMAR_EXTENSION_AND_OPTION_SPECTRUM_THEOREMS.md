## III. Classical exact mathematical consequences

**R6-T1: two-direction option monotonicity.** If X→*_G Y is stagewise safe, then \(\Gamma_G(Y)\subseteq\Gamma_G(X)\). If \(G\hookrightarrow G'\) is a conservative enlargement then \(\Gamma_G(X)\subseteq\Gamma_{G'}(X)\) and \(V_g^{G'}(X)\le V_g^G(X)\) for every fixed customer endpoint goal g (including infinities; all old weighted paths still exist). These are entirely classical path inclusion arguments. Proof: concatenate the first safe path to every Y-successor path, and respectively embed every old path in the enlarged path set. These two monotonicities are DIFFERENT: along a committed source edit options may contract, while widening permitted interventions can restore options.

**R6-T2: residual-minimal abstraction cannot become coarser under conservative alphabet enlargement.** Fix a set \(S_0\) of original reachable source/right worlds and an original exact legal old-edit suffix language \(R^G_s\subseteq\Sigma^*\). Write \(s\equiv_G t\iff R^G_s=R^G_t\). Assume G' conservatively preserves every old suffix and makes new edits available on an extended alphabet \(\Sigma'\supseteq\Sigma\). If \(s\equiv_{G'}t\), restricting their equal new suffix languages to \(\Sigma^*\) gives \(s\equiv_Gt\). Hence \(\equiv_{G'}\subseteq\equiv_G\) on \(S_0\), i.e. grammar extension may force the minimal full-future quotient to **refine**, never merge formerly distinguished original states. This is a classical Myhill–Nerode language restriction theorem. It can fail if old path admission/rights or client observations are redefined rather than preserved. For weighted effect/goal right languages, the same result holds when all old action labels, path receipts and query interpretations are included unchanged.

**R6-T3: exact criterion for preserving the old 64-class quotient.** A preexisting quotient map \(q:S_0\to Q\) remains sound for the extended declared future-query language iff the new residual query answer functions are **constant on every q-fibre**. Necessity: a well-defined abstract answer at q(s) cannot give two different answers. Sufficiency: define the abstract answer as their common value. When q was already minimal under G and extension is conservative, q remains minimal iff *no old q-fibre is split* by a new legal suffix/effect/goal query. This is the central source-certifiable condition to test next.

**R6-T4: source-lawful example of forced split, NOT an actual Go source claim.** On the 96 old P13 legal label-subset worlds \(X=(T,z)\), T⊆Q={A,B,C,D,G}, z∈{none,E,F}, old admission-minimal q merges (T,E) with (T,F) for all 32 T. Then one-letter suffix U distinguishes all 32 previously merged pairs. All other q-fibres were already separated by an old suffix, so the minimal *new legal-admission quotient restricted to the original 96 states* has **exactly 96** distinct blocks, versus 64 before. If instead U is enabled symmetrically and has identical continuation behavior on (T,E) and (T,F), the 64-block quotient might survive.
