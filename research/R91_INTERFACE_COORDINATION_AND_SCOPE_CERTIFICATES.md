## Unit A — Shared-interface coordination gap
Finite nonempty shared-interface set Z, finite real local optimal costs c_i(z), fixed demand, same contract and objective. Conditional independence permits total cost sum_i c_i(z). Independent relaxation L=sum_i min_z c_i(z); coordinated optimum H=min_z sum_i c_i(z).
Gap G=H-L >=0; equality iff intersection of local argmin sets nonempty. Proof: each local regret c_i(z)-min c_i nonnegative, zero total iff all vanish at same z. Write R_i=max c_i-min c_i. Select a minimizing interface of an index with largest R_i; remaining regrets <= their ranges. Thus G<=sum R_i-max R_i. Finite bound, no claim with infinite costs. Pairwise compatible local optima need not be jointly compatible: three interface choices and cost rows [0,0,1], [1,0,0], [0,1,0]; every pair has gap zero, whole has gap one. JavaScript 3x2 costs in {0,1,2}: 729 tables, 375 tight range-bound cases. Code tools/paper_b_r91_interface_coordination.mjs, cb1741b7. Known separable optimization and Helly-style obstruction; software semantics not established.

## Unit B — Hidden-variable boundary theorem
Binary demand variables d and finite independent-domain hidden decision variables z, arbitrary finite cost factors phi_alpha supported on specified scopes. F(d)=min_z sum_alpha phi_alpha(d_scope,z_scope). Build hidden-variable co-occurrence graph (edges whenever two hidden variables appear in a factor); each factor containing hidden variables belongs to exactly one hidden connected component. For a component C let B_C be its incident demand variables. Pure demand factors have own scopes. Group factors by component: conditional on d, minimization separates exactly across independent hidden components; hence F is a sum of factors with scopes B_C and pure-demand scopes. Therefore all Boolean Möbius coefficients outside the downward closure of these scopes vanish. Max order <= maximum scope cardinality. This is a standard variable-elimination consequence, not automatically novel.
Sharpness in unrestricted binary factor-table class: for a pure-demand scope of size b, use product of its b bits. For a hidden connected component with boundary b>=2, use spanning-tree equality penalties to tie its hidden bits to common z; for each incident demand choose one factor containing that demand and one hidden variable and charge d_i if z=0; add unary cost b-1 for z=1. Equality penalty > b suffices, all finite. Then optimized cost is min(|S intersect B|,b-1), with order-b Möbius coefficient -1. Irrelevant variables/factors set zero. For b=1 choose a demand-only unary term embedded in an allowed factor. Thus largest boundary is sharp as worst-case expressivity under unrestricted factors; NOT a necessary lower bound for a particular cost instance. Scope graph is not proof of true code semantics or path-cost factorization. Reconfiguration path feasibility must be modeled separately or proved equivalent. A single shared bit can induce unbounded order despite local pairwise factors.
Verified constructed split model 32 states order 2, connected-chain model 16 states order 4 coefficient -1; pure factor witness +1. tools/paper_b_r91_hidden_boundary.mjs, d5280e5a.

## Unit C — Query budget under independently certified scopes
Let D be the downward closure of allowed demand scopes, containing empty set; F(empty)=0. Assuming all other Möbius coefficients vanish, query F(A) for A in D excluding empty; recursively recover coefficients by inclusion and then evaluate all F(S). Exact number |D|-1, often far smaller than full 2^n-1. For arbitrary real coefficients in this normalized linear space, deterministic exact reconstruction requires >= |D|-1 queries worst case: on zero transcript (or strictly monotone additive baseline if each variable is covered), each observed value imposes one linear constraint on coefficient perturbations; fewer queries leave a nonzero kernel, small perturbation retains strict monotonicity if baseline and singleton coverage assumed. Same transcript, distinct functions. This dimension argument concerns exact value reconstruction, not approximate testing or source analysis. Fixture n=6 scopes {0,1,2},{2,3},{4,5}: 12 queries, 64 states reconstructed; hidden interaction outside promise evades observed values. Fixture coefficients need not define monotone software costs. tools/paper_b_r91_scope_queries.mjs, 3886441d.
