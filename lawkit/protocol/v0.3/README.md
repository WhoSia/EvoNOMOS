# EvoNOMOS LawKit Protocol v0.3

v0.3 adds **fresh-world admission**.

The input is a world envelope frozen before treatment birth. LawKit checks conjunctive scientific gates and compiles structural pressure signals. It does not score repositories and does not choose a design.

Required gates:
- exact pre-demand source lock;
- independent real initial demand;
- independent real paired follow-up demand;
- pair frozen before treatment;
- discrimination from prior worlds;
- outcome surface frozen;
- observability firewall frozen.

The output may identify:
- membership-propagation pressure relevant to CIL-C1;
- pre-existing-boundary pressure;
- capability-bundle mismatch relevant to CBL-C1;
- auth/capability heterogeneity.

The output must never recommend DIRECT, INVERT, interface splitting, SOLID compliance, or another design before a prospective treatment court.

The protocol is canonical; implementation language is not.
