# EvoNOMOS LawKit Protocol v0.5

v0.5 adds adversarial fresh-world discovery.

The protocol does not rank repositories by a scalar score. It asks which candidates satisfy a conjunction of scientific gates and which **law candidate they are capable of falsifying**.

For CBL-C1, a strong adversarial world has:
- a pre-existing abstraction boundary;
- a real new implementation demand;
- demand capabilities that cover most or all capabilities bundled by the existing boundary;
- low or absent capability-bundle mismatch at admission;
- clean pre-demand source;
- no treatment-bearing implementation leakage;
- preferably an independently observed paired follow-up.

If such a world later shows capability segregation benefits anyway, CBL-C1's current mechanism story is weakened. If wide-boundary reuse carries no conformance burden and no worse lifecycle cost, that is direct boundary evidence against overgeneralizing CBL-C1.

The protocol is canonical; implementation language is not.
